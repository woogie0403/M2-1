# 사용자 피드백과 개선 기록

> **문서 기준일**: 2026-10-24 (KST) · **운영 배포 기준**: [`0bc17dc`](https://github.com/sayknow/M2-1/commit/0bc17dca34f3ec6479549248798e76bfcb962064) · **관련 문서**: [최종 제출 목차](README.md) · **[실사용자 5명 응답 원본 기록](evidence/user-test-records.md)**

서비스 타깃인 **‘다이소 영양제를 처음 고르거나 표시정보를 비교하려는 일반 성인’ 5명(`T1`~`T5`, 팀원 제외)**을 대상으로 사용성 테스트를 진행하고, 수집된 핵심 불편 사항 5가지(**사이트 주소 식별성 · AI 질문 범위 · AI 첫 시작 질문 오류 · 일상의 활력 추천 결과 · 비슷한 포장 변형 중복 추천**)를 코드와 운영 환경에 반영했습니다.

## 3. 공통 확인 질문 및 개인정보 보호 기준

실사용자 테스트는 아래 6개 확인 질문을 기준으로 진행했으며, 참여자의 실제 질환·복용 의약품·병원 검사 수치·실명·연락처는 일절 질문하거나 수집하지 않았습니다.

1. 사이트 주소와 첫 화면을 보고 어떤 서비스인지 설명할 수 있었나요?
2. 설문을 혼자 완료할 수 있었나요? 이해하기 어려운 선택지는 무엇이었나요?
3. 추천 이유와 후보 간 차이를 이해할 수 있었나요? 비슷한 제품이 반복됐나요?
4. ‘함량과 기준량’ 시작 질문과 직접 작성한 일반 성분 질문에 답변·출처를 받을 수 있었나요?
5. 비교 해설·표에서 고르는 데 도움이 된 정보와 부족한 정보는 무엇이었나요?
6. 오류·정보 부족 안내가 나왔을 때 다음 행동을 알 수 있었나요?

*(참여자가 제안한 부가 의견 중 ‘인근 다이소 매장 실시간 재고 연동(T1)’과 ‘타 쇼핑몰·약국 제품 비교(T4)’는 정적 라벨 검수 DB 기반의 프로젝트 범위를 벗어나므로 반영하지 않고 [응답 원본 기록 4절](evidence/user-test-records.md)에 미반영 사유를 명시했습니다.)*
