## 2. 공통 확인 질문 (6개 문항)

참여자에게 실제 개인 질환·처방약 대신 일반 성인 조건으로 서비스를 자유롭게 탐색하도록 안내한 뒤, 아래 6개 공통 질문을 기준으로 응답을 기록했습니다.

1. **Q1 (주소·첫인상)**: 사이트 주소와 첫 화면을 보고 어떤 서비스인지 설명할 수 있었나요?
2. **Q2 (설문 진행)**: 설문을 혼자 완료할 수 있었나요? 이해하기 어려운 선택지는 무엇이었나요?
3. **Q3 (추천 납득도)**: 추천 이유와 후보 간 차이를 이해할 수 있었나요? 비슷한 제품이 반복됐나요?
4. **Q4 (AI 상담·출처)**: ‘함량과 기준량’ 시작 질문과 직접 작성한 일반 성분 질문에 답변·출처를 받을 수 있었나요?
5. **Q5 (제품 비교)**: 비교 해설·표에서 고르는 데 도움이 된 정보와 부족한 정보는 무엇이었나요?
6. **Q6 (오류·안전 안내)**: 오류·정보 부족 안내가 나왔을 때 다음 행동을 알 수 있었나요?
