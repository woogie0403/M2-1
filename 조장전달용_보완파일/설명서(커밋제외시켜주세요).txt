3. 저장소 반영 및 Git Push 방법 (그대로 복사하여 실행)
--------------------------------------------------------------------------------

[Step 1] 파일 덮어쓰기
  - 이 폴더 안의 `README.md` 파일과 `docs` 폴더를 로컬 `M2-1` 저장소 루트 폴더에
    그대로 복사(덮어쓰기)합니다. (`설명서(커밋제외시켜주세요).txt`는 복사하지 않으셔도 됩니다.)

[Step 2] 변경 파일 및 문서 검증 스크립트 확인
  git status --short
  python3 scripts/validate_final_docs.py

[Step 3] 스테이징, 커밋 및 푸시 (`README.md`와 `docs/`만 정확히 스테이징)
  git add README.md docs/
  git commit -m "docs(final): 실사용자 5인 응답 원본, 팀원 기여 증빙, 12p 발표자료 PDF 및 서비스 작동 스크린샷 반영"
  git push origin production
